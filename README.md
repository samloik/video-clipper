# video-clipper

Вырезает фрагменты видео по таймкодам из YouTube, TikTok, VK, Rutube, Instagram и любого
другого сайта, который умеет [yt-dlp](https://github.com/yt-dlp/yt-dlp), а также из локальных
файлов. Есть CLI и минимальный локальный веб-интерфейс.

## Установка

```bash
cd ~/programs/video-clipper
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
cp config.example.json config.json    # поправь пути под себя
```

Нужен `ffmpeg` в PATH (`sudo apt install ffmpeg`). Поддерживается ffmpeg 4.x — синтаксис
5+/6+ (`-fps_mode` и подобные) не используется.

## Быстрый старт

```bash
# YouTube: один фрагмент
video-clipper "https://youtu.be/ID" --range 1:12-1:45

# TikTok: скачать и вырезать (прокси и cookies — из config.json)
video-clipper "https://www.tiktok.com/@user/video/123" --range 0:05-0:20

# локальный файл, несколько фрагментов
video-clipper ~/Videos/lecture.mp4 --range 0:10-0:25 --range 12:00-12:30

# список отрезков из CSV: start,end,name
video-clipper "https://youtu.be/ID" --csv clips.csv

# быстрый режим: без перекодирования, точность до ключевого кадра
video-clipper video.mp4 --range 1:00-1:20 --fast

# только посмотреть, что будет нарезано (URL не скачивается)
video-clipper "https://youtu.be/ID" --range 0:10-0:20 --dry-run

# веб-GUI на 127.0.0.1:8765
video-clipper-gui
# или
video-clipper --gui
```

Таймкоды: `SS`, `SS.mmm`, `MM:SS`, `HH:MM:SS`, `HH:MM:SS.mmm` (запятая как разделитель тоже
принимается). Имя файла по умолчанию — `<slug>__<начало>__<конец>.mp4`; переопределяется
`--name` (только один отрезок) или третьей колонкой CSV.

## Режимы

| режим | флаг | точность | скорость |
|---|---|---|---|
| точный (по умолчанию) | `--accurate` | кадровая | перекодирование H.264/AAC |
| быстрый | `--fast` | до ключевого кадра | без перекодирования (`-c copy`) |

В быстром режиме границы могут сместиться к ближайшему ключевому кадру — на коротких клипах
это заметно, поэтому по умолчанию включён точный режим.

## Веб-интерфейс

`video-clipper-gui` поднимает сервер **только на 127.0.0.1** (порт из конфига, по умолчанию
8765) и открывает браузер. На странице: зона drag & drop (файл загружается в `cache/`),
поле ссылки, два поля таймкода, галочка быстрого режима, кнопка «Нарезать», список готовых
файлов со ссылками. Нарезка идёт в фоне, ошибки показываются в интерфейсе. Внешних JS и CDN нет.

## Конфигурация

`config.json` (см. `config.example.json`), значения перекрываются флагами CLI:

- `output_dir` — куда складывать фрагменты (`./output`)
- `cache_dir` — куда скачивать исходники (`./cache`, удаляются после нарезки)
- `default_resolution` — максимальная высота при скачивании (720)
- `cookies` — путь к `cookies.txt` для yt-dlp (не хранится в git)
- `proxy` — например `socks5://127.0.0.1:10808`
- `ffmpeg_path`, `ffprobe_path`, `keep_source`, `gui_host`, `gui_port`, `log_file`
- `use_sections` — скачивать только нужные участки через `download_ranges` (по умолчанию
  `false`: на части сайтов такой режим зависает, поэтому он экспериментальный; при `true`
  срабатывает, когда отрезки покрывают ≤40% видео)

## Telegram-бот

Основной канал общения: присылаешь ссылку и таймкоды — бот отвечает готовыми роликами.

```bash
# 1. токен от @BotFather положи в файл (в чат его присылать не нужно)
printf '%s' '123456:ABC...' > ~/.hermes/video-clipper-bot.token
chmod 600 ~/.hermes/video-clipper-bot.token

# 2. свой chat_id узнаешь у бота командой /id, впиши в config.json:
#    "telegram_chat_ids": [370180073]

# 3. запуск
systemctl --user daemon-reload
systemctl --user enable --now video-clipper-bot
journalctl --user -u video-clipper-bot -f
```

Формат сообщений:

```
https://vm.tiktok.com/ZSpFs5jXJ/ 0:10-0:20
https://youtu.be/ID 0:05 0:12 fast
<ссылка>
0:10-0:20
0:30-0:40
```

Команды: `/id`, `/status` (что лежит на машине), `/clean` (удалить всё сейчас), `/help`.

Режим без перекодирования доступен двумя способами: словом `fast`/`быстро` в сообщении или
кнопкой **«⚡ Без перекодирования (быстро)»** под готовым роликом — она перерезает тот же
отрезок через `-c copy` из уже скачанного файла, без повторной загрузки (секунды вместо минут).
Кнопка живёт `retention_minutes`; если исходник уже удалён, бот попросит прислать ссылку заново.

## Хранение файлов

- Оригинал живёт `retention_minutes` (по умолчанию 30) с момента последнего использования —
  повторная нарезка той же ссылки идёт из кеша, без скачивания.
- Клипы — столько же; после отправки в Telegram копия в чате остаётся, на машине чистится.
- Чистка запускается при каждом запросе и раз в минуту в боте; вручную — `/clean`
  или `video-clipper ... ` (CLI чистит только `cache/`).

## Отчёт

`--json-report report.json` пишет по каждой нарезке: путь, начало, конец, фактическую
длительность, режим и размер, плюс итоги по прогону.

## Тесты

```bash
.venv/bin/python -m pytest tests/ -q
```

Тесты не ходят в сеть: yt-dlp мокается, видео для интеграционных тестов генерируется
локально через `ffmpeg -f lavfi -i testsrc`.

## Ограничения

- Длительность в контейнере может быть на 1–2 кадра больше заказанной из-за гранулярности
  AAC-кадров; видеоточная длительность точная.
- Нет встроенной поддержки субтитров и вертикального кропа — отложено (см. план в Plan Manager).
- Сервер GUI без аутентификации: только localhost.
